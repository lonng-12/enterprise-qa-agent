# 企业知识库智能问答 Agent

基于 FastAPI + RAG + ChromaDB + DeepSeek 的企业知识库问答系统。

## ✨ 核心功能
- 📄 文档上传与解析（支持 PDF/TXT）
- 🔍 基于 RAG 的检索增强生成
- 🤖 Agent 工具调用（Function Calling）
- ⚡ SSE 流式对话输出

## 🛠️ 技术栈
- **后端框架**：Python, FastAPI, Uvicorn
- **大模型**：DeepSeek API (兼容 OpenAI SDK)
- **向量检索**：ChromaDB, SentenceTransformer
- **其他**：Pydantic, Docker, Git
